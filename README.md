# Flashcard App

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Learning Tool](https://img.shields.io/badge/learning-tool-green.svg)]()

A flashcard learning app with spaced repetition (SM-2 algorithm).

## ✨ Features

- **Decks** - Create and organize flashcard decks
- **Cards** - Add question/answer cards
- **Spaced Repetition** - SM-2 algorithm for optimal learning
- **Study Sessions** - Interactive study with scoring
- **Progress Tracking** - Track your learning progress
- **Tags** - Tag cards for easy filtering
- **Import/Export** - CSV/JSON/Anki format support
- **Statistics** - Detailed learning reports

## 📦 Installation

```bash
git clone https://github.com/Master-626/flashcard-app.git
cd flashcard-app
pip install .
```

## 🚀 Quick Start

```bash
# Create a deck
flashcards create-deck "Spanish Vocabulary"

# Study a deck
flashcards study "Spanish Vocabulary"

# View stats
flashcards stats
```
